# BabyCare Tracker

## Описание
Мобильное приложение для отслеживания ухода за детьми. Простой и интуитивный интерфейс для родителей и опекунов.

## Стек технологий
- React Native (Expo, TypeScript)
- Supabase (PostgreSQL, Auth, Storage)
- OneSignal (push-уведомления)

## Быстрый старт
1. Установите зависимости:
   ```bash
   cd app
   npm install
   ```
2. Запустите Expo:
   ```bash
   npx expo start
   ```
3. Настройте переменные окружения для Supabase и OneSignal (см. `.env.example`)

## Структура репозитория
- `app/` — Expo React Native приложение
- `docs/` — документация, схемы, ТЗ
